## クォータ（切れ目はグローバル）

```bash
gcloud compute regions describe asia-northeast1 --project=monzi-sandbox --format=json
gcloud compute project-info describe --project=monzi-sandbox --format=json
```

| メトリクス | limit | usage | 意味 |
| --- | --- | --- | --- |
| `NVIDIA_L4_GPUS`（東京） | **1** | 0 | 地域の L4 は 1 枚まで空いている |
| `PREEMPTIBLE_NVIDIA_L4_GPUS` | 1 | 0 | Spot 用 L4 も地域は 1 |
| **`GPUS_ALL_REGIONS`（グローバル）** | **0** | 0 | **全リージョン合計の GPU が 0。地域 1 でも insert 不可** |
| `NVIDIA_A100_GPUS` | 0 | 0 | A100 は対象外 |
| `A2_CPUS` | 0 | 0 | A2 機種そのものが 0 |
| `PREEMPTIBLE_CPUS` | **0** | 0 | Spot の vCPU が 0。L4 Spot クォータがあっても Spot は立てられない |
| `CPUS`（東京） | 100 | 0 | `g2-standard-8` の 8 vCPU は足りる |
| `G2_CPUS` | （regions.describe に項目なし） | | 一般 `CPUS` で足りると判断 |

地域 L4=1 だけ見て「立てられる」は誤り。グローバル `GPUS_ALL_REGIONS` が別に要る（[Compute GPU 制限](https://cloud.google.com/compute/docs/gpus#restrictions)）。

## insert が弾かれた理由（無料枠が先）

GPU の insert は REST `instances.insert`（ゾーン `asia-northeast1-a`、`g2-standard-8` + `nvidia-l4` ×1、Ubuntu 22.04、pd-balanced 80GB、`onHostMaintenance=TERMINATE`）。クエリに `dryRun=true` を付けた。

**HTTP 400。VM は作られていない。** 本文:

> Your billing account is currently in the free tier where non-TPU accelerators are not available. Please upgrade to a paid billing account as described here: https://cloud.google.com/free/docs/gcp-free-tier#how-to-upgrade

公式: 無料トライアルでは VM に GPU を付けられない。クォータ増も申請できない。[Free Trial の制限](https://cloud.google.com/free/docs/free-cloud-features)

切れ目の順（2026-09-13 時点）:

1. **請求先が無料枠** → GPU そのものが禁止（ここで 400）
2. 有料化のあと **`GPUS_ALL_REGIONS` を 0→1**（地域 L4 は既に 1）
3. そのあとゾーン在庫。`ZONE_RESOURCE_POOL_EXHAUSTED` なら a→b→c を試す

2026-09-14 の読み取りでは 1 は人が Paid 化した前提。2 は **まだ 0**。insert は再撃っていない。

Spot は `PREEMPTIBLE_CPUS=0` なので、有料化しても追加申請なしでは使えない。対話検証はオンデマンド `g2-standard-8` が先。

## 誤作成（CPU）と削除

対照として e2-micro の同じ REST を撃ったところ、`dryRun=true` でも **実インスタンス `cpu-probe-only` が STAGING→RUNNING になった**。東京 e2-micro は Always Free 対象外。約 2 分で削除:

```bash
gcloud compute instances delete cpu-probe-only \
  --project=monzi-sandbox --zone=asia-northeast1-a --quiet
```

見る場所: `Deleted [.../instances/cpu-probe-only]` のあと `gcloud compute instances list` が空。GPU は一度も立っていない。

以降、確認に CPU insert は使わない。

## 2026-09-14 夜: `GPUS_ALL_REGIONS` が 1

人がコンソールで `GPUs (all regions)` を 0→1 申請。約 1 分で承認。insert はしていない。YAML の `rg -A2` は次項目の `limit` を拾うので、JSON で切った。

クォータは通った。create / stop / delete を書くなら `local-llm-test` と `google-cloud-skill-challenge` の外の新規。置き場所の候補は `~/dev/`（名前は後で）。入れない場所:
